الأجهزة المتصلة

أرسل /start للبوت، ثم أضف رقم المحادثة الذي يرسله لك هنا. فقط الأرقام المضافة تستطيع استخدام البوت.

ماذا يفعل البوت؟

💸
اكتب 350 إيجار أو فقط 350 → يسألك مصروف أم دخل → الفئة → يُحفظ ويظهر هنا فوراً
📊
ملخص الشهر: الدخل، المصاريف، الصافي، ونسبة كل فئة
👥
المشتركين: النشطين، تنتهي قريباً، الإيقافات
📝
طلبات التسجيل: يعرض النموذج كاملاً مع أزرار موافقة / رفض
🔔
تنبيه فوري عند كل تسجيل جديد أو إيقاف مؤقت

التشغيل

1
في تيليجرام افتح @BotFather → /newbot → انسخ الـ Token
2
شغّل البوت من مجلد bot/ (تعليمات كاملة في SETUP.md)
3
أرسل /start للبوت وأضف الـ Chat ID أعلاه
